# Quti Ustasi — qisqa dizayn (tasdiqlangan 2026-11-18)

**Maqsad:** flexbox'ni bilgan, lekin sahifani qutilarga bo'la olmayotgan bolalar uchun mustaqil o'ynaladigan o'yin.
**Nega:** Flex Parkovka xususiyatlarni o'rgatadi; bu o'yin undan oldingi ko'nikmani — dizayndan qutilarni ko'rishni — mashq qildiradi.

## Yondashuvlar
1. Faqat belgilash (kodsiz) — kodga ko'prik yo'q.
2. Faqat kod — hozirgi muammoga yordam bermaydi.
3. **Ikki bosqichli daraja (tanlangan):** avval Ko'r (qutilarni belgilash, flex/bo'shliq kimga), keyin Yoz (HTML/CSS).

## Qarorlar
- Bolalar mustaqil ishlaydi: tekshiruv natijaga (element joyiga) qarab, xato nomi bilan aytiladi, 3 pog'onali podskazka, "qutilarni ko'rsat", har darajadan so'ng "nega".
- 6 bob, 30–40 daraja: quti ichida quti; flex kimga; padding/margin/gap; container; to'liq seksiyalar; final landing.
- Bitta HTML fayl, toza JS dvigatel (bolalar faqat HTML/CSS yozadi), serversiz, progress brauzerda, faqat kompyuter.
- v1'da yo'q: o'qituvchi paneli, akkauntlar, reyting.

## Vizual reja (mening qarorim)
Chizma (blueprint) mavzusi: ko'k katak fon, oq "qog'oz" varaqlar, sariq marker, qizil qalam bilan bo'shliq zonalari.
Shrift: Bahnschrift (sarlavha), Segoe UI (matn), Cascadia/Consolas (kod). Tashqi resurs yo'q.
